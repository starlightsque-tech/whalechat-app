# WhaleChat mobile

Capacitor shells that wrap the WhaleChat web bundle for Android and iOS.

```
npm install
WC_SYNC_SERVER=https://chat.yourdomain.com npm run bundle   # refresh www/ + bake server URL
npx cap sync                                                # copy www/ into android + ios
```

## Android

```bash
npx cap open android          # or build from the CLI
cd android && ./gradlew assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
cd android && ./gradlew assembleRelease    # sign the unsigned release with your keystore
```

- appId: `app.whalechat.mobile` · versionName 3.2.0 · versionCode 6 · minSdk 22 · targetSdk 34
- Icons: adaptive launcher icons generated in `res/mipmap-*`; splash in `res/drawable*`.
- The web bundle ships inside `assets/public/`, so the app launches offline and then syncs.

## iOS

```bash
npx cap open ios      # requires macOS + Xcode + CocoaPods
```

Set a signing team, then Product → Archive. Push notifications for iOS need an APNs key
uploaded to your Apple developer account; web push works once the app is added to the Home Screen.

## Notes

- `www/` is generated by `scripts/build-mobile.mjs` — never edit it by hand.
- The service worker is disabled inside the native shell to avoid double caching; the app's
  local database still works offline and reconnects when the server is reachable.
- Change `server.androidScheme` only if you also migrate localStorage, or users lose their
  local session.
